Flux Atlas globe lab: attribution and licences
==============================================

Everything in labs/globe/src is original work written for Flux Atlas (a clean-room rewrite; no code
from earlier versions of the project). This file lists everything else that ships in the lab's
public/ folder or is bundled into its build, where it came from, and the terms it comes with.
Nothing is hotlinked at runtime: every texture, map and font is served from this folder.

----------------------------------

3. Network snapshot (public/data/flux-snapshot.json, flux-snapshot.bin)
----------------------------------------------------------------------

A compact, columnar snapshot of the public Flux network (node locations, tiers, status, app
locations, sampled peer links) taken on 2026-09-30 from the public Flux API dumps collected by the
Flux Atlas research team. It carries no IP addresses, no collateral hashes and no payment addresses.
Node ids are row numbers. One column is partly synthetic, and says so in the file's "note": the
ArcaneOS flag is set at a 38% rate because the source does not expose it. scripts/build-fixture.mjs
builds it.

5. The Flux symbol (public/brand/Flux_symbol-mark_blue.svg)
-----------------------------------------------------------

The official Flux symbol from the Flux media kit, copied unchanged from assets/brand/flux/symbol. It
is the shape of the "Flux moon" in the globe. Flux, the Flux logo and the Flux symbol are
trademarks of their owners. The renderer follows the rules of the Flux Brand Book (v2.0) as
summarised in assets/brand/flux/README.md: the symbol is drawn only in Flux blue #2B61D1, white,
black, gray or the tonal blue of the brand guides, with its proportions unchanged, and no tier color
ever touches it. It stands for the Flux chain in a Flux ecosystem tool; it is not the logo of this
project.
