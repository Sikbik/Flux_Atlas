Brand: the Flux symbol and Atlas

Atlas wears the Flux brand. Blue Wave #2B61D1 is the one accent, Montserrat and Open Sans carry the words, and the symbol appears only in white, black, Blue Wave and the book's grays. The full rules, clear space and misuse are on the brand sheet.

Surfaces and materials

Depth comes from one light source at the top left. Windows are opaque slabs because the globe repaints every frame behind them; only small chrome uses glass.

Typography

The brand book pairs Montserrat with Open Sans and keeps Lora for accents. Montserrat carries titles, display numerals, buttons and tier names. Open Sans carries text. Lora appears once per view as an editorial line. IBM Plex Mono carries data. Live numbers use tabular figures so columns never jitter. Sentence case everywhere.

Buttons, inputs, tabs

Five button levels. Only one chamfered primary per view. Focus is a two-ring outline that works on every surface.

Badges, status, freshness, connection

Tier colour is reserved for tiers and always paired with the three-capsule glyph. Status colour is reserved for state and always paired with an icon and a word.

The moon

The Flux symbol, extruded in Blue Wave, orbits the globe: the moon is the chain. A hexagon ring fills over the 30 second block interval. The pieces map to payouts: the cap is Stratus, the big hexagon is Nimbus, the small hexagon is Cumulus, and the bar is the development fund. All of it is drawn live in canvas; these are stills of the same renderer.

Stat tiles, numbers, sparklines

Numbers that change roll like an odometer, digit by digit, only the digits that changed. Reduced motion swaps to a 120 ms cross-fade.

Live lists: Pulse feed

Every live item enters the same way: row height opens in 280 ms, a coloured bar decays over 1.6 s, and bursts collapse instead of scrolling.

Block rail and time machine

Newest block on the right. A hatched ghost card stands for the block in progress and fills over 30 s.

Windows, dock, inspector parts

A window is one content component hosted by a frame. The same component fills a desktop window, a docked inspector, a tablet sheet or a phone sheet.

Command palette rows

One field resolves heights, hashes, transaction ids, addresses, IPs, ports and app names. Results are grouped and keyboard-first.

Data components

Tables are dense and sticky-headed. Health runs on one stepper with real thresholds. Secrets are never drawn.

Empty, loading, error

Each state says what happened and what to do next, in the voice of the interface. Errors never apologise and are never vague.
